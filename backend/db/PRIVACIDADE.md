# Política de Privacidade - Performance Quest

## Dados coletados
- Nome, turma e matrícula do aluno
- Respostas e desempenho no quiz

## Finalidade
- Gerar ranking e relatórios pedagógicos
- Melhorar o aprendizado dos alunos

## Compartilhamento
- Os dados não são compartilhados com terceiros

## Retenção
- Os dados são mantidos apenas durante o período da atividade de extensão
- Após esse período, serão eliminados

## Segurança
- Acesso restrito à equipe do projeto
- Banco de dados protegido por senha
